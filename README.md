# AnimeSearchv1

This project will made it for practice, A web application to search and explore anime information using the Jikan API

## Installation

```bash
git clone https://github.com/brayanangelcast/animesearchv1.git
cd animesearchv1
npm install
```

## stack

> - React
> - Next.js
> - TailwindCSS
> - Jikan API (anime data)
> - Vercel

## How to run

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## API Used

[Jikan API](https://docs.api.jikan.moe/) - Free anime data API
